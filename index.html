Splaterra

A real place, rebuilt in 3D.

Video of the VJTI campus becomes a scene you can explore, using Gaussian splatting.

read the blog ↗ code ↗

Splaterra is a 3D reconstruction project for long camera trajectories. It turns campus walkthrough videos into photorealistic, interactive 3D scenes using Gaussian splatting, camera pose estimation and depth prediction, keeping quality consistent along the whole path. It suits robotics, autonomous navigation, embodied AI and digital twins.
